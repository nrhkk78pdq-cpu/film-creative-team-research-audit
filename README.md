# Film Creative Team Research Dataset Audit

This repository supports a non-commercial academic feasibility audit on film project management and creative team collaboration.

The project examines whether publicly available movie metadata and crew credits can support research on director–cinematographer collaboration, visual creative team configuration, and film performance.

The project may use the TMDB API to retrieve movie metadata, release information, production company information, external IDs, and crew credits for non-commercial academic analysis.

## Data Source Attribution

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB data will be used only for non-commercial academic research and feasibility assessment.
